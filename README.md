## What they share

- **No dependencies.** Each one is plain TypeScript you can read in an afternoon.
- **Pure rules.** Every move makes a new state and changes nothing it was given, so a game can be saved as text, replayed, and checked on a server.
- **Seeded.** The same seed deals the same game in every browser.
- **Ready to play.** A drawing and a playable board for any page, as a call or a tag, with touch, mouse and keyboard.
- **English and Japanese**, a Help switch on every demo, and light and dark.
- **MIT licensed.** Art and sound are drawn for the packages or CC0, credited where used.
